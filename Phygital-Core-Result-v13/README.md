# Phygital Core

Текущая версия: v13. Исправления заголовков и новая серия прозрачных объектов описаны в [docs/ITERATION-13.md](docs/ITERATION-13.md). Предыдущие изменения: [docs/ITERATION-12.md](docs/ITERATION-12.md).

Полностью адаптивный frontend платформы фиджитал-турниров. Проект работает без backend: аккаунты, сессия, профиль и административные изменения сохраняются локально в браузере. Стек сохранён — React 19, TypeScript 5.9, Next.js App Router API через Vinext, Vite 8 и Cloudflare Workers.

## Запуск

Требуются Node.js 22.13+ и npm 10+.

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173`.

Проверки и production-сборка:

```bash
npm run lint
npm run build
npm run start
```

## Маршруты и права

Публичные страницы: `/`, `/tournaments`, `/teams`, `/rules`, `/faq`, `/contacts`, `/privacy`. Отдельные маршруты турниров, входа и регистрации удалены; авторизация работает в едином модальном окне поверх текущей страницы.

`/profile` требует авторизации. Для гостя открывается модальное окно входа с возвратом в запрошенный раздел после успешной авторизации.

Административные страницы `/admin`, `/admin/users`, `/admin/teams`, `/admin/teams/applications`, `/admin/tournaments`, `/admin/tournament-applications`, `/admin/logs` требуют роли `ADMIN`. Авторизованный пользователь без этой роли видит страницу 403.

## Архитектура

Код следует Feature-Sliced Design и направлению зависимостей `app → pages → widgets → features → entities → shared`:

- `src/app` — App Router, layouts, providers, error boundaries и глобальные стили;
- `src/views` — физическое размещение FSD-слоя `pages`, доступного через alias `@/pages`;
- `src/widgets` — публичный header/footer и административная оболочка;
- `src/features` — авторизация, профиль и административные сценарии;
- `src/entities` — модели и начальные данные User, Team, Tournament, Application;
- `src/shared` — UI, API-контракты, data source, конфигурация, storage и утилиты.

Каталог `src/pages` намеренно не создаётся, чтобы Next.js не включал устаревший Pages Router. Логический FSD-слой `pages` экспортируется из `src/views/index.ts`. Публичные API slices оформлены через `index.ts`.

Поток данных авторизации: `UI → AuthProvider → authService → localDataSource → localStorage`. Админ-данные проходят через `AdminStore → adminService → IndexedDB`. Чтобы подключить REST API, достаточно заменить реализации сервисов/data source, не переписывая страницы.

## Реализованные сценарии

- реальный локальный вход, регистрация, выход, восстановление сессии и две роли;
- редактируемый профиль с сохранением после перезагрузки и сменой пароля;
- защищённые маршруты, страницы 403/404 и error boundary;
- заявка на турнир с выбором существующей команды, автоматическим определением капитана и необязательным комментарием до 500 символов;
- FAQ с заданным набором тем и рабочей формой вопроса;
- создание команды администратором через динамический список игроков, поиск зарегистрированных пользователей, удаление игрока и выбор одного капитана из состава;
- состояния поиска игроков: загрузка, результаты, ничего не найдено, ошибка и повтор;
- создание турнира только с разрешёнными полями; статус рассчитывается автоматически по датам;
- рабочие поиск, фильтры, сброс, вкладки, пагинация, просмотр, создание, редактирование, решения по заявкам, роли, сброс пароля, подтверждение удаления и административный лог;
- loading/disabled, валидация и сообщения об успехе/ошибке для мутаций;
- единая тёмная неоновая тема, responsive UI для desktop/tablet/mobile и reduced-motion режим;
- непрерывная анимированная лента ценностей и scroll-reveal анимации на публичных страницах;
- viewport-safe модальные окна через portal: фон блокируется, содержимое прокручивается независимо и не конфликтует с футером.

## Графика

Локальные декоративные изображения находятся в `public/` и имеют оптимизированные WebP-версии:

- `hero-arena-v2.webp` — главный экран;
- `trophy-arena.webp` — турниры;
- `team-arena.webp` — команды.
- `rules-arena.webp` — правила и сочетание реальной арены с цифровой тактикой;
- `faq-core.webp` — центр знаний и FAQ;
- `contacts-network.webp` — контакты и коммуникационная сеть.

Изображения не содержат встроенного текста, интерфейсных элементов, чужих логотипов или товарных знаков. PNG-исходники оставлены рядом для дальнейшей обработки.

## Локальные данные

Демо-версия не передаёт введённые данные на сервер. Очистка данных сайта в браузере сбрасывает аккаунты, сессию, профиль и административные изменения к начальному состоянию.
